# 아시아 종목 라이브러리 (5-B, 65종 + ADR 1종)

아시아 세션 서술 시 활용할 수 있는 종목 풀. `_data.json`의 `stocks` 카테고리에 매일 06:50 KST 새벽 수집된 데이터가 들어 있다 (`close`, `day_chg`, `week_chg`, `month_chg`, `ytd_chg`).

**활용 원칙**:
- 일본·중국·인도·대만 시장 서술 시 "닛케이 +N%" 수준에서 끝내지 말고 **대표 종목 1-2개의 일변동률**까지 인용해 구체화
- 단, 본문에 종가·등락률을 쓸 때는 `_STOCK_ALIASES` 등록된 이름을 사용해야 자동 검증을 통과 (등록 외 이름은 검증 누락)
- 종목 5-6개를 나열하지 말고, **그날 흐름을 가장 잘 보여주는 1-2종**만 선별
